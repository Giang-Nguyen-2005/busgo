## Information hierarchy

The existing fieldset/legend accessibility and review/edit/creation behavior remain. Review separates journey, contact/payment key-values, money and one primary creation action. Completion still uses the existing booking-detail destination; it was not changed or captured.

Bus Detail status options reuse the Vietnamese bus-status mapping while retaining enum values; its active tab uses existing green/orange tokens, with quieter inactive tabs. No per-row fetching.

Customer detail gives name the primary emphasis, account type/contact supporting emphasis, and identity caveats metadata emphasis. Booking, journey and mock-payment groups each have one leading value. Booking-history rows separate code/source, booking badge, journey, seats/creation timestamp, payment badge, ticket counts/attendance, contact, cancellation and money. Transactions remain in native details. No field-level cards added. Mixed seat attendance and mock gross/refund/net values are preserved.

Customer directory retains all table columns and data. Name/type, phone/email, route, booking count and money now have distinct emphasis. Contact cells retain table-cell layout so borders align. Latest journey has no supplied departure timestamp; latest booking activity remains in its original separate column. Customer history explicitly labels `createdAt` as “Tạo đặt vé”; no invented journey date.

Typography reuses the current Inter/Segoe UI/Arial foundation and semantic tokens for text, muted text, green, orange, surfaces and borders. Existing page titles remain 24–28px; new section titles 17–18px; identities 15–17px; support 13–14px; metadata 12–13px; badges use the existing 13px system. Leading metrics use 28px. No global typography reset. Lucide is already installed and is retained in existing navigation and seat controls; no new icon library or decorative icons. Phone step titles use numbers.
